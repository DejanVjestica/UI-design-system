# GovUI Design System (Lit + Storybook)

A lightweight design system built with **Lit Web Components** and documented in **Storybook**.

The project focuses on **accessibility (WCAG)**, **reusability**, and **scalable UI architecture** for enterprise and public-sector applications.

---

## 🚀 Tech Stack

- Lit (Web Components)
- TypeScript
- Vite
- Storybook
- pnpm

---

## 🧩 Components

Current components:
- button
- input
- card
- modal

Each component is built with:
- accessibility-first design (WCAG / ARIA)
- reusable and framework-agnostic architecture
- encapsulated styling via Web Components
